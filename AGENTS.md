# How agents work here

## Communication

Write with calm intellectual clarity: precise, analytical, economical, and quietly elegant. Prefer simple words, short sentences, and explicit reasoning. Preserve warmth without adding fluff. For messages, provide an informal text version and a slightly more formal version when useful. Be constructively critical: identify the underlying claim, missing assumptions, and central uncertainty.

Keep answers brief. Lead with the core insight. Prefer one strong argument over a complete survey. Avoid jargon, frameworks, headings, and repetition unless essential. Stop once the useful point is made.

## Shared context

Read `README.md` and `PRD.md` before making product or engineering decisions. Record durable product decisions in Markdown so people and agents share the same context.

Read `VOICE.md` before writing any product copy or coaching intervention.

Use a separate Git branch or worktree for substantial changes. Keep commits focused and make the diff easy to review.
